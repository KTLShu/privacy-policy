📄 一叶文档搜索 · 隐私政策

100% 本地离线全文解析 · 文档内容绝不上传 · 纯净安全
生效日期：2026年11月16日 · 最近更新：2026年11月16日
核心隐私承诺：
【一叶文档搜索】（Leaf Doc Search）是一款纯本地离线运行的文档全文检索与工作台工具。本应用绝不会将您的任何文档文件、文档正文内容、搜索关键词、文件名列表、通讯录或个人身份信息上传、存储或共享至任何远程服务器。所有文件扫描、压缩流解压、PDF/Office 文本提取与文本编辑操作均 100% 在您的设备本地完成。

1. 我们如何处理您的数据

本地文档索引与全文解析：为了实现文件名秒搜及 PDF、Word（.docx/.doc）、Excel（.xlsx/.xls/.csv/.tsv）、PPT（.pptx/.ppt）、纯文本（.txt/.md/.json 等）的正文关键词定位，应用仅在设备本地内存与存储内读取您所选范围的文档并提取匹配片段。所有解析、解密（仅限无打开密码的本地权限锁 PDF）与高亮计算过程均严格在本地执行，绝不通过网络向外传输任何文档内容或关键词。

本地缓存与搜索历史：为提升二次搜索速度，应用会在应用私有沙盒目录中持久化保存轻量的本地文档索引元数据（路径、大小、修改时间），并在内存中维护有上限的近期解析片段缓存；您的最近搜索历史、目录范围、格式偏好及排除目录配置仅保存在本地 SharedPreferences 中。您可以随时清空搜索历史或关闭应用以释放内存缓存，所有本地数据随应用卸载自动彻底删除。

内置轻量文本编辑：当您使用内置纯文本预览/编辑器修改并保存 .txt 等文本文件时，所有编码识别与写回操作均直接在本地文件系统执行，不经过任何中间服务器。

2. 设备权限使用说明

本应用严格遵循最小必要权限原则申请系统权限，所有权限均仅在本地检索、授权目录访问或文件编辑时使用：

所有文件访问权限 (MANAGE_EXTERNAL_STORAGE)
必要核心权限：作为专业全盘文档检索工具，应用需要遍历并只读解析您设备存储空间（内部存储与外置存储）中的各类文档正文，或在您主动编辑保存纯文本文件时写入更改。绝不用于任何未经授权的后台读取、篡改或外传行为。

3. 第三方 SDK 与数据服务声明

不同分发渠道集成的基础服务有所区分，具体如下：

Google AdMob（仅 Google Play 版本）
  • 使用目的：在「最近搜索历史」弹窗等非核心检索区域展示轻量级横幅广告，以支持应用的持续免费维护与更新。
  • 数据收集范围：广告标识符（AAID / Advertising ID）、IP 地址估算粗略地理位置、设备基础信息及广告展示/点击交互数据，具体受 Google 隐私权政策 及当地用户同意框架（UMP）约束。
  • 隐私边界：广告 SDK 绝对无法访问您的本地文件系统、文档内容、文件名或搜索关键词。
Google Firebase 套件（仅 Google Play 版本）
  • Firebase Crashlytics（崩溃监控）：仅用于捕获未捕获异常与 ANR 堆栈信息（含机型、系统版本、内存状态），帮助修复大文档解析稳定性问题，不收集文件内容、路径或搜索词。
  • Firebase Analytics（匿名统计）：仅统计匿名实例 ID、系统语言与功能使用概览，严格禁止采集任何搜索关键词、文件路径或个人身份数据。
  • Firebase Remote Config（远程配置）：仅在启动时拉取只读版本提示与合规配置键值，不回传用户本地数据。
部分版本使用一叶官方统计与远程配置服务（AppTracker）
  • 使用目的：用于统计应用的日常活跃指标与新增去重，以及安全拉取版本公告和动态免审配置。
  • 数据收集范围：设备机型、操作系统版本、应用版本号及 Android ID（SSAID，用于匿名设备去重）。
  • 隐私边界：在您点击同意本隐私政策前，绝对不收集任何设备标识；严格禁止并绝不收集手机号、IMEI、MAC 地址、剪贴板、通讯录或任何文件内容。

📄 Leaf Doc Search · Privacy Policy

100% Offline Full-Text Parsing · Zero Document Uploads
Effective Date: November 16, 2026 · Last Updated: November 16, 2026
Our Privacy Commitment:
Leaf Doc Search is a standalone, 100% offline full-text document search and workbench utility for Android. We do NOT collect, upload, store, or share your document files, document text contents, search keywords, filenames, contacts, or personally identifiable information to any external server. All file scanning, stream decompression, PDF/Office text extraction, and text editing occur strictly locally on your device.

1. Data Handling & Local Processing

Local Indexing & Full-Text Extraction: To provide instant filename filtering and full-text keyword search across PDF, Word (.docx/.doc), Excel (.xlsx/.xls/.csv/.tsv), PowerPoint (.pptx/.ppt), and plain-text files (.txt/.md/.json, etc.), the app reads files strictly locally on your device. All parsing, local permission-lock PDF decryption (only for PDFs without an open password), and snippet highlighting are executed on-device and never transmitted over any network.

Local Cache & Search History: To accelerate repeat searches, lightweight document index metadata (path, size, last modified timestamp) is cached locally in the app's private sandbox, and recent search history, scope settings, and format preferences are stored solely in local SharedPreferences. You can clear search history at any time, and all local caches are permanently deleted upon app uninstallation.

Built-in Text Viewer & Editor: When you inspect or edit plain-text files, encoding detection and file saving are executed directly against your local storage without any server involvement.

2. App Permissions & Justification

All Files Access (MANAGE_EXTERNAL_STORAGE)
Core Functional Requirement: Strictly required for a full-device document search tool to traverse and read document contents locally across internal storage and SD cards, as well as save user-initiated edits to plain-text files. Never used for unauthorized background access or external transmission.

3. Third-Party SDKs & Services (Google Play Release)

For Google Play builds (com.oneleaf.docsearch.play), we integrate the following official Google services (completely excluded from domestic/China builds):

Google AdMob
  • Purpose: Displays a lightweight banner advertisement inside the recent search history popup to support ongoing development.
  • Data Collected: Advertising ID (AAID), coarse location inferred from IP, basic device info, and ad interaction metrics in accordance with the Google Privacy Policy and applicable user consent (UMP).
  • Privacy Safeguard: AdMob has zero access to your local storage, document contents, filenames, or search keywords.
Google Firebase Suite (Crashlytics, Analytics, Remote Config)
  • Firebase Crashlytics: Captures anonymized crash stack traces, device model, OS version, and memory state to improve large-document parsing stability. Never collects file contents, paths, or search keywords.
  • Firebase Analytics: Collects anonymous Firebase App Instance IDs and aggregate app usage metrics. Strictly prohibited from capturing search queries, filenames, or personal identifiers.
  • Firebase Remote Config: Fetches read-only runtime configuration flags and update notices upon launch.
AppTracker (Lightweight Active Metrics)
  • Purpose: Counts basic daily active launches (DAU) and app version deduplication (and remote notices on domestic builds).
  • Data Collected: Device model, OS version, app version, and Android ID (SSAID). Never collects phone numbers, IMEI, MAC addresses, contacts, search keywords, or document contents.
